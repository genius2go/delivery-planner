Delivery Planner · Quick Guide

How To Use It

A passage-planning tool for the Florida–New England corridor. Build a route from a curated list of stops, adapt it as conditions change, and produce a clean report for the boat owner.

Building a plan

1Client & Boat: enter the vessel, client/owner, the boat's max range per leg, and cruise speed. Choose north or southbound.
2Pick Stops: the list runs in geographic order. Tap the stops you want — they auto-sequence along the coast.
3Sequence: drag to reorder or remove stops as weather and plans change.
4Generate Plan: you get leg distances, time at your cruise speed, range warnings if a leg is too long, per-leg maps, and the Coast Guard Notice to Mariners districts to check. Print / Save PDF for a clean plan.

Underway

Need an unplanned stop? The Underway box in the Sequence area adds a port (name + rough position + a note) and slots it into the route.

Recording the trip

1Each stop has a ✓ Confirm button — tap it when you arrive, set the date, add a quick note.
2At the end, open Delivery Report, add dates/crew/summary, and Print / Save PDF for the owner. Leave Include per-stop notes off for a clean client version.
Note: this copy is read-only for the shared stop list — you can build plans, confirm stops, and print reports in a sitting. To save trips that persist across days and devices, you'd want your own copy with your own GitHub setup. Ask Peter.
Always navigate on current official charts, ATON, and live weather. This tool supplements planning — it never replaces them.
