✍ Trip Debrief — capture what you learned

After a trip, run through your stops. Only record what would change how you (or another captain) run it next time — skip the nice-to-know. Each note saves back to that stop in the master list.

▸ 📝 Delivery Report — record a completed trip

After a delivery, capture how it actually went. Generates a clean report you can print/PDF for the client, and saves a dated entry to your trip log (trips.json) on GitHub.

⚙ Master List — save new knowledge (your devices only)

Ports you added underway live only in this plan until you deliberately commit them to the shared master list. This needs your GitHub token — without one, the planner still reads the master list and builds plans, it just can't write back. Anyone you share the tool with gets read-only.
